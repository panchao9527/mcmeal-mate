# 90 秒演示

1. 启动 `python -X utf8 -m mcmeal serve`，打开本机演示。说明页面使用 2026-10-09 的官方历史快照。
2. “四个人一起吃饭，我要汉堡薯条，小王主食不要牛肉，小李饮料无糖、总参考能量不超过600，小陈想吃辣，预算150。”观察每人方案、共享小食、分账与验收单。
3. 点击“优先省钱”，解释硬性要求保留、软偏好发生取舍；展示候选内两种目标的差异。
4. 点击“预算降到120”，显示重新安排后的每人餐；保持所有成员和硬性要求。
5. 点击“试试预算不足”，说明系统返回冲突，不通过漏掉成员来凑预算。
6. 展示 `examples/quoted-15000-preference.json` 的真实整单核价和 `live-quote-evidence.json`，解释浏览器历史演示的“待核实”与现场真实核价的“通过”。

收尾：“大家负责想吃什么，麦麦搭子负责把一顿饭安排明白。”

## v0.2 实际使用演示

切换“实时配餐” → 输入城市和地标 → 查询营业门店并选择 → 增删、重命名成员并编辑要求 → 填预算 → 点击“安排一下” → 观看真实查询进度 → 检查当前官方核价时间及每人分账。

早餐示例可加载 `examples/request-v02-breakfast.json` 所述三人要求（主食和饮料，不强制薯条）；10月10日真实核价为62.50元。此金额仅代表记录时刻。修改任意需求后，旧方案会标记失效，需重新生成；菜单缓存也不复用整单报价。
