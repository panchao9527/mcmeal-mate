# 可选可视化工作台

这是v0.1/v0.2保留的本机网页演示，便于查看约束和分账。v0.3的Skill主流程在AI客户端聊天中运行，安装包不包含本页面所需代码。

在完整源码仓库中执行：

```text
python -X utf8 -m mcmeal serve
```

打开 `http://127.0.0.1:8765`。历史模式使用2026-10-09的公开门店快照，当前官方价格显示待核实；该地址只能在运行服务的本机访问。

网页的独立实时模式仍使用旧直连适配器，需要本机环境变量`MCD_MCP_TOKEN`，或显式使用`serve --token-file`。它不能自动复用AI客户端的连接。该认证路径仅属于可选工作台，Skill主流程使用宿主MCP，不需要此配置。

网页支持编辑1至8位成员、选择营业门店、读取早餐/正餐精选候选和整单核价。旧适配器只覆盖预选餐品，不代表Skill主流程的动态候选能力。
